Tiny URL service

Shorty

Paste a long destination and mint a short address. Opening that address sends the customer to the same URL. Leave it unused and it expires.

Merchant sign-in

Create and vanity assign send these as HTTP Basic credentials. Opening a tiny URL does not.

Destination

Leave vanity blank and Shorty picks a code. To rename a destination that already has a tiny URL, enter a free vanity and choose Assign vanity. You can also paste an existing tiny URL into Long URL when assigning.

Original destination

Open a tiny URL

Opens in a new tab. The service redirects to the stored destination. No sign-in is required.
