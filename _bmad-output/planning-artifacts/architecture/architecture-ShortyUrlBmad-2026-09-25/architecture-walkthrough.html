Request path

Create pipeline

Mint path (story-critical)

Before the write

  • Basic Auth (create / vanity)
  • Sanitize long URL
  • Liveness via RestClient — 2xx or 3xx wins; do not follow redirects
  • 404 fails immediately; timeout/5xx → 3 × 30s

Atomic bind

  • Lookup by sanitizedUrl
  • Existing → return current tiny URL
  • New → write binding in one transaction
  • Store original pasted URL, not redirect target

Invariants AD-1 … AD-4

What builders must not break

AD-1

Layered single deployable

One Spring Boot process; controllers hold no binding or liveness rules.

AD-2

Service sole mutator

Create, vanity, and last-access all go through transactional service methods.

AD-3

H2 is the store

No second store for bindings; JPA + H2 only.

AD-4

Liveness inside create

Probe before the bind transaction; retries only for timeout/5xx.

Invariants AD-5 … AD-8

Security, runtime, identity

AD-5

One filter chain

Basic Auth on create/vanity; resolve permitAll.

AD-6

Local single process

Embedded Tomcat; no multi-instance shared H2 assumptions.

AD-7

Inactivity config

Configurable window (5 min for testing); miss/expired never redirect.

AD-8

Binding identity

Stable id; unique mutable shortCode; unique sanitizedUrl for idempotency; mute short form.

Data shape

Binding entity

One row per destination binding

  • id — stable surrogate PK
  • shortCode — unique, mutable (vanity)
  • originalUrl — merchant paste, immutable for the binding
  • sanitizedUrl — unique idempotency key
  • lastAccessedAt — resets inactivity window

Vanity assign changes shortCode only. Existing sanitized URL never gets a second binding.
